## Features <br />
-Skeletal animation with blending between states <br />
-Idle, walking, running, punching, sword slashing, sword sheathing, item grabbing <br />
## Controls <br />
WASD -> move<br />
LShift -> sprint<br />
E -> equip/drop item
F -> attack
Q -> sheath/unsheath sword (if equipped)
